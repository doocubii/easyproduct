# 풀 리뷰 — {{날짜}} (계기: {{계기}})

> LLM 층 점검(산문 충실도·미러 충실도·파장 확인)의 **흔적**이다. 이 파일이 없으면 그 점검은 **미실행**으로 본다.
> 기계 점검(`check-docs.mjs`)이 통과했다는 사실은 여기 적지 않는다 — 그건 다른 층이고, 통과가 곧 검증 완료가 아니다.

## 범위

- **진원지**: `{{그 결정이 사는 문서 경로}}` *(최초 완성 리뷰면 "없음")*
- **파장 지도로 계산된 하류**: {{n}}개
- **리뷰 종류**: 전체 / 부분(수정 항목 + 파장)

## 단계별 파생 확인

파장 지도 순서대로 내려가며, 각 쌍에서 **두 질문**에 답한 결과를 적는다.
(① 상류의 이 변경이 이 문서에 무엇을 낳는가 ② 이 문서에 새로 생긴 요구가 다음 문서에 무엇을 낳는가)

- [ ] `{{상류}}` → `{{하류}}` : {{반영함/영향없음/보류}} — {{무엇을}}
- [ ] `{{상류}}` → `{{하류}}` : …

## 미해결 / 판단 보류

- {{없으면 "없음"}}

## 지도 밖이었던 것 (있으면)

작업 중 **예측 목록에 없던 문서**를 고치게 됐다면 여기에 적는다. 이건 실수 기록이 아니라
**파장 지도가 틀렸다는 증거**이며, 다음에 지도를 고치는 근거가 된다.

- `{{경로}}` — {{왜 고쳐야 했는지 / 지도에 어떤 관계가 빠졌는지}}

```json review.snapshot
{
  "reviewedAt": "{{YYYY-MM-DD}}",
  "trigger": "{{계기}}",
  "origin": "{{진원지 경로 — 없으면 이 필드 삭제}}",
  "scope": "partial",
  "sources": [
    { "path": "{{상류 문서 경로}}", "revision": 1, "contentHash": "sha256:{{그때의 해시}}" }
  ],
  "checked": [
    { "from": "{{상류}}", "to": "{{하류}}", "result": "반영함", "note": "{{무엇을 반영했는지}}" }
  ],
  "unresolved": [],
  "outOfMap": []
}
```

> **`sources`의 스냅샷이 이 문서의 기계적 쓸모다.** 상류 문서의 그때 상태(개정 번호 + 내용 해시)를 적어 두면,
> 점검기가 "리뷰 이후 상류가 또 바뀌었는지"를 판정해 하류에 경고를 띄울 수 있다.
> 해시는 점검기가 계산해 준다(`check-docs.mjs <루트> --print-snapshot`).
